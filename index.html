🎯 Objetivo de Aprendizaje

Los estudiantes podrán: comprender la eficiencia de la repetición en procesos inteligentes, para usar Micro:Bit programando parpadeos y secuencias con bucles y variables y automatizar tareas.

🤖 Prompt de Referencia para XOLO (Solo para Maestro)

⚠️ NOTA: XOLO ya conoce el tema de esta misión. Este prompt es SOLO de referencia en caso de emergencia técnica: 
Explícame qué es un bucle y por qué repetir instrucciones ahorra tiempo y hace que el programa sea más eficiente. Enséñame a usar “repetir X veces” para hacer parpadeos o secuencias. Después guíame a leer un GCS que combine bucles con una variable (por ejemplo, contar repeticiones) para entender cómo se automatizan tareas.

Usar el Micro:Bit para repetir animaciones o luces automáticamente.

🚨 Resolución Rápida de Problemas

  • Si los alumnos no pueden ingresar a Gnius Space: Activa XOLO SOS en xolo.gnius.club para continuar la misión sin interrumpir la clase.
  • Si el micro:bit no responde: Verificar batería o conexión USB. Intentar descargar el programa nuevamente.
  • Si el bucle no se detiene: Revisar que el número de repeticiones en el bloque sea el correcto.
  • Si hay errores en el código: Recordar a los estudiantes que XOLO puede ayudar a depurar. Pídeles que copien el error y se lo muestren a XOLO.

📊 Diapositiva 3: Brain Spark

1. 💬 Pide a XOLO que te ayude a crear:

"Ayúdame a idear un proyecto aplicado con vibe (por ejemplo: “alarma luminosa”, “parpadeo de celebración”, “secuencia de energía”). Quiero que el Micro:bit repita una animación varias veces y cuente cuántas repeticiones hizo. Genera el GCS usando repetir + variable y acompáñame a implementarlo en bloques de MakeCode."

2. 🔬 Experimenta y descubre con tu programa:

  • ¿Funciona la animación tantas veces como le pediste?
  • ¿Qué pasa si pones un número de repeticiones muy grande en el bucle?
  • ¿Funciona igual si cambias la velocidad del parpadeo dentro del bucle?
  • ¿Cómo ayuda el bucle a que tu programa sea más eficiente que escribir cada paso a mano?
  • ¿Por qué decimos que la repetición es la base de un proceso inteligente o automatizado?

¡Es hora de crear! Vamos a usar lo que aprendimos para hacer un proyecto con mucho VIBE. Piensen: ¿quieren una alarma, una animación de energía o un parpadeo de fiesta? El flujo es fácil: platiquen su idea con XOLO, definan el VIBE, obtengan su GCS y pásenlo a MakeCode. Por ejemplo, podrían hacer una carita que parpadea 10 veces y cuenta cada guiño. Experimenten con las preguntas que ven en pantalla. Cuando su simulador funcione, les daré su Micro:Bit real para probarlo. Si tienen errores o dudas, pregúntenle a XOLO, él los ayudará a depurar.
